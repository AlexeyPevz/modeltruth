# Agent Instructions — modeltruth

Описание проекта — `README.md` и `docs/`. Ниже — правила для облачных агентов.

## Облачные агенты (Devin)

Раздел для облачных агентов (Devin), которые получают задачи из Linear (команда `ALE`) и работают на своей машине, а не на компьютере владельца.

- Один тикет — одна ветка от свежего `main` — один PR в `main`. Заголовок PR: `[ALE-<n>] <описание>`. В описании: что сделано, какие проверки запущены и с каким результатом, что не проверено, риски, ссылка на тикет.
- PR не мержить, в `main` не пушить. Мержит только владелец.
- Менять только то, что входит в тикет. Проблему вне тикета описать в тикете, не чинить в этом PR.
- Неясное требование или нет доступа — вопрос в тикете, не угадывать. Секреты в комментариях не запрашивать и в код, логи и PR не писать.
- Не трогать прод, деплой, реальные базы данных, SSH и платежи. Локальные пути вида `D:\...`, worktree и `.env` относятся к компьютеру владельца, в облаке их нет.
- Репозиторий публичный: никаких ключей, приватных эндпоинтов и данных владельца в коммитах, тестах и фикстурах.

Проверки перед PR:

- `test -z "$(gofmt -l .)"`
- `go vet ./...`
- `go test -race ./...`

Если проверка не запускается в облаке, написать в PR, чего не хватило. Не выдавать зелёный CI за прохождение проверки, которую CI не запускает.

CI — свой сервер Woodpecker, не GitHub Actions: статус в PR `woodpecker/pr/ci`, сборка стартует после одобрения мейнтейнера. Подробно — `docs/ci.md`.
